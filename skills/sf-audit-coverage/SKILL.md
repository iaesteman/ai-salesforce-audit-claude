# Skill: sf-audit coverage

Run a standalone Salesforce Apex test coverage audit on a live org.

## Activated by
`/sf-audit-coverage [org-alias]`

## What This Skill Does

Analyzes Apex test coverage for the target Salesforce org using the Tooling API. Identifies classes and triggers below Salesforce's 75% deployment threshold, assesses recent test run health, and produces an actionable coverage report.

Output file: `SF-TEST-COVERAGE.md` (written to current directory)

---

## Phase 1: Connectivity Check

Run the following to confirm the org is accessible:

```bash
sf org display --target-org [org-alias] --json
```

If this fails:
- If no org-alias was provided: run `sf org list --json` and prompt the user to specify an alias
- If authentication has expired: instruct the user to run `sf org login web --alias [alias]`
- Do not proceed until the org is confirmed accessible

Extract and display:
- Org Name, Username, Org ID, Edition, Instance URL

---

## Phase 2: Run Coverage Queries

Execute all queries via the Bash tool using `--use-tooling-api`:

```bash
# 1. All Apex class and trigger coverage
sf data query --target-org [org-alias] --use-tooling-api \
  --query "SELECT ApexClassOrTrigger.Name, ApexClassOrTrigger.Id, NumLinesCovered, NumLinesUncovered FROM ApexCodeCoverageAggregate ORDER BY NumLinesUncovered DESC" \
  --json

# 2. Recent test run results
sf data query --target-org [org-alias] --use-tooling-api \
  --query "SELECT AsyncApexJobId, Status, ClassesCompleted, ClassesFailed, MethodsCompleted, MethodsFailed, CreatedDate FROM ApexTestRunResult ORDER BY CreatedDate DESC LIMIT 5" \
  --json

# 3. Recent test failures
sf data query --target-org [org-alias] --use-tooling-api \
  --query "SELECT ApexClass.Name, MethodName, Outcome, Message, StackTrace, CreatedDate FROM ApexTestResult WHERE Outcome = 'Fail' ORDER BY CreatedDate DESC LIMIT 50" \
  --json

# 4. Active triggers (for trigger-specific coverage)
sf data query --target-org [org-alias] --use-tooling-api \
  --query "SELECT Id, Name, TableEnumOrId FROM ApexTrigger WHERE Status = 'Active'" \
  --json

# 5. All active Apex classes (for test class ratio)
sf data query --target-org [org-alias] --use-tooling-api \
  --query "SELECT Id, Name, ApiVersion FROM ApexClass WHERE Status = 'Active' ORDER BY Name" \
  --json
```

## Phase 3: Calculate & Score

**Org-wide coverage:**
```
total_covered   = SUM(NumLinesCovered)
total_uncovered = SUM(NumLinesUncovered)
org_coverage_pct = total_covered / (total_covered + total_uncovered) × 100
```

**Per-class coverage:**
```
class_pct = NumLinesCovered / (NumLinesCovered + NumLinesUncovered) × 100
```
Flag all where `class_pct < 75` AND total lines > 0.

**Trigger coverage:**
Cross-reference trigger IDs against coverage records. Flag triggers < 75%.

**Test class ratio:**
- Production classes = classes where Name does NOT contain "Test"
- Test classes = classes where Name contains "Test"
- Ratio = production / test count

**Scoring (0–10 per dimension):**

| Dimension | Weight | Thresholds |
|-----------|--------|------------|
| Org-wide coverage % | 35% | ≥90%=10, 80-89%=8, 75-79%=6, 60-74%=4, <60%=1 |
| Classes below 75% | 25% | 0=10, 1-2=8, 3-5=6, 6-10=4, >10=2 |
| Test class quality | 20% | Ratio ≥1:3 + recent runs passing = 10; ratio ok = 7; low ratio = 4; no tests = 0 |
| Trigger coverage | 20% | All ≥75%=10, 1 below=6, 2+ below=3, untested triggers=1 |

```
section_score = (org_score×0.35 + below_score×0.25 + quality_score×0.20 + trigger_score×0.20) × 10
```

**Grade:**
| Score | Grade |
|-------|-------|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| < 50 | F |

## Output Standards
- If `ApexCodeCoverageAggregate` returns 0 records: note "No coverage data found — run tests first: `sf apex run test --target-org [alias] --synchronous`"
- Never fabricate coverage numbers
- Always name specific classes in recommendations

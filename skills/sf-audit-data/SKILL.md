# Skill: sf-audit data

Run a standalone Salesforce data quality audit on a live org.

## Activated by
`/sf-audit-data [org-alias]`

## What This Skill Does

Analyzes data completeness, hygiene, and duplicate risk across core Salesforce objects (Contact, Account, Lead, Opportunity, Case). Identifies missing critical fields, stale records, orphaned data, and gaps in duplicate detection rules.

Output file: `SF-DATA-QUALITY.md` (written to current directory)

---

## Phase 1: Connectivity Check

```bash
sf org display --target-org [org-alias] --json
```

If this fails, instruct the user to authenticate: `sf org login web --alias [alias]`

Extract and display: Org Name, Username, Org ID, Edition.

sf data query --target-org [org-alias] \

  --query "SELECT COUNT() FROM Account WHERE Phone = null AND IsDeleted = false" --json

  --query "SELECT COUNT() FROM Account WHERE BillingCity = null AND IsDeleted = false" --json

# --- LEAD ---
sf data query --target-org [org-alias] \
  --query "SELECT COUNT() FROM Lead WHERE IsConverted = false AND IsDeleted = false" --json

  --query "SELECT COUNT() FROM Lead WHERE IsConverted = false AND CreatedDate < LAST_N_DAYS:90 AND IsDeleted = false" --json

  --query "SELECT COUNT() FROM Case WHERE ContactId = null AND AccountId = null AND IsClosed = false" --json

## Phase 3: Calculate & Score

**Null rate formula:**
```
null_rate = null_count / total × 100
```

**Score per field (0–10):**
| Null Rate | Score |
|-----------|-------|
| < 5% | 10 |
| 5–14% | 8 |
| 15–29% | 6 |
| 30–49% | 4 |
| 50–74% | 2 |
| ≥ 75% | 0 |

**Status thresholds:**
- OK = < 15% null
- WARN = 15–40% null
- CRITICAL = > 40% null

**Dimension scores:**
- Contact = avg(Email score, Phone score, Account score)
- Account = avg(Industry score, Type score, Phone score, BillingCity score)
- Lead = avg(stale lead score, missing email score)
- Duplicate = Active rules for Account + Contact + Lead (10/7/4/0 based on count)
- Opportunity = avg(stale opp score, overdue close date score)

```
section_score = (contact×0.25 + account×0.20 + lead×0.20 + duplicate×0.20 + opp×0.15) × 10
```

**Grade:**
| Score | Grade |
|-------|-------|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| < 50 | F |
